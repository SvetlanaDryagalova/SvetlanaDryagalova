`Python` · `LangChain` · `FAISS` · `Sentence Transformers` · `PyMuPDF` · `Gemini`

`Python` · `OpenCV` · `NumPy` · `scikit-image` · `Matplotlib`

`Explainable AI` · `PDP / ALE` · `SHAP` · `UMAP`
